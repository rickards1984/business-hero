## 1. Executive Summary — Top 10

1. CRITICAL — ~30 tables have no RLS enabled (tasks, calls, quotes, businesses, whatsapp_*, financial_summary_cache, executive_meeting_*). Frontend writes to tasks/support_tickets directly with the public anon key, proving `authenticated` has table grants — any logged-in user can read/write every tenant's rows. Evidence: models.py; frontend/client/src/components/EmailsTab.tsx:335; no ENABLE ROW LEVEL SECURITY in migrations.
2. CRITICAL — xero_connections RLS effectively open: SELECT policy is a tautology; service policy FOR ALL USING(true) has no role restriction. Xero token ciphertext readable by any user. supabase/migrations/013_xero_integration.sql:55-65.
3. CRITICAL — accounting_connections FOR ALL USING(true) WITH CHECK(true), no role. All accounting tokens exposed. supabase/migrations/019_accounting_providers.sql:98-99.
4. HIGH — Twilio WhatsApp webhook has no X-Twilio-Signature validation. Forged replies trigger numbered pending actions. whatsapp_briefing_api.py:448-524.
5. HIGH — Twilio voice webhooks /incoming-call + /media-stream: no signature, no auth. receptionist_call_handler.py:466,532.
6. HIGH — No rate limiting anywhere. All OpenAI endpoints are unthrottled billing weapons (ai/generate accepts 5 hi-res images/call). quoting_api.py:949; main.py:2011,2049.
7. HIGH — quotes/quote_settings/quote_line_items exist only in the live DB (no migration, no model). No RLS, schema drift. quoting_api.py:133,238,303.
8. HIGH — Money engine uses float for all currency math; VAT on summed total with banker's-rounding round(). quoting_api.py:51-72,294-327.
9. MEDIUM — Invoice numbers via COUNT(*)+1: races on concurrent conversion, collides after deletes. quoting_api.py:531-535.
10. MEDIUM — Most OpenAI clients unhardened (no timeout/retry cap); only app/email/service.py has timeout=30.0,max_retries=1. Contributes to 3-5 min page loads. openai_utils.py:26; assistant_chat.py:746; main.py:2085; receptionist_api.py:594,707; services/briefing_generator.py:38,137.

## 2. Findings Register

Severity: CRITICAL/HIGH/MEDIUM/LOW · Lens: SEC/COR/PERF · Effort: S(<half day)/M(1-2d)/L(>2d)

Impact: cross-tenant read/write via PostgREST with the public anon key; tasks provably reachable. Fix: enable RLS + is_business_member policies (Batches 4-6). Effort L.
- SEC-02 CRITICAL SEC — 013_xero_integration.sql:55-65 — SELECT policy tautology + service policy FOR ALL USING(true) no role. Any user reads/writes all Xero token ciphertext. Fix: is_business_member scoping; service policy TO service_role. Effort S.
- SEC-03 CRITICAL SEC — 019_accounting_providers.sql:98-99 — accounting_connections FOR ALL USING(true), no role. All provider tokens exposed. Fix: same as SEC-02. Effort S.
- SEC-04 HIGH SEC — whatsapp_briefing_api.py:448 — no X-Twilio-Signature check. Forged inbound triggers actions. Fix: RequestValidator against TWILIO_AUTH_TOKEN. Effort S.
- SEC-05 HIGH SEC — receptionist_call_handler.py:466,532 — Twilio voice endpoints unauthenticated/unsigned. Fix: validate signature; sign media-stream TwiML URL. Effort M.
- SEC-06 HIGH SEC — quoting_api.py:949; main.py:2011,2049; support_api.py:209; email AI routes — no rate limiting. Unbounded OpenAI spend. Fix: slowapi per-business limiter; cap images/calls. Effort M.
- SEC-07 HIGH SEC — quotes tables no migration — core money tables not in migrations/ORM. No RLS, non-reproducible. Fix: add migration + RLS. Effort M.
- SEC-08 MEDIUM SEC — main.py:303,314-323 — CORS allow_origin_regex ^https://.*\.vercel\.app$ + allow_credentials. Any attacker *.vercel.app is allowed origin (LOW in practice: Bearer-token auth, not cookies). Fix: pin exact prod domain(s). Effort S.
- SEC-09 MEDIUM SEC/PERF — supabase_auth.py:21-76 — JWT verified via remote /auth/v1/user every request; no local alg/aud/iss check. Latency + Supabase dependency. Fix: local JWKS verification. Effort M.
- SEC-10 MEDIUM SEC — providers/token_refresh_lock.py:21-28 — refresh lock is in-process asyncio.Lock; no cross-worker coordination. With >1 worker the single-use Xero refresh race persists. Fix: pg advisory lock or SELECT FOR UPDATE. Effort M.

- SEC-13 LOW SEC — auth.py:44-77 — MASTER_ADMIN_KEY compared with != (not constant-time). Fix: hmac.compare_digest. Effort S.

### Correctness (money engine)
- COR-01 HIGH COR — quoting_api.py:51-72,294-327 — float currency math; VAT on summed total; round() banker's. Penny drift across quote/PDF/invoice. Fix: Decimal end-to-end, ROUND_HALF_UP quantize 2dp, consistent VAT strategy. Effort M.
- COR-02 MEDIUM COR — quoting_api.py:1084-1089 — float(item.get("unit_cost",0)): missing cost silently becomes £0; non-numeric 500s. Fix: Pydantic-validate AI lines; never silent zero. Effort S.
- COR-03 MEDIUM COR — quoting_api.py:531-535 — INV-{COUNT(*)+1}: races + collides after deletes vs uq_invoice_business_number. Fix: per-business sequence in locked txn. Effort M.
- COR-04 MEDIUM COR — quoting_api.py:507-566 — convert_to_invoice copies only total; line items/per-line VAT/qty not transferred. Fix: copy lines + tax; assert sum(lines)+vat==total. Effort M.

Policy template (business-owned table):
  ALTER TABLE <t> ENABLE ROW LEVEL SECURITY;
  CREATE POLICY "<t>_admin_all" ON <t> FOR ALL TO authenticated
    USING (is_platform_admin(auth.uid())) WITH CHECK (is_platform_admin(auth.uid()));
  CREATE POLICY "<t>_member_select" ON <t> FOR SELECT TO authenticated
    USING (is_business_member(auth.uid(), business_id) OR is_platform_admin(auth.uid()));
  CREATE POLICY "<t>_member_write" ON <t> FOR INSERT TO authenticated
    WITH CHECK (is_business_member(auth.uid(), business_id));
Token tables (xero_connections, accounting_connections, oauth_tokens): deny authenticated entirely; rely on service role.

Required indexes (PERF-04): business_id index on every Batch 4-6 table lacking one; email_sync_states(email_account_id); confirm business_members(user_id,business_id,is_active). Mark helper functions STABLE.

Migration order:
1. Create quotes/quote_line_items/quote_settings migration (capture live schema) — unblocks SEC-07.
2. Fix xero_connections + accounting_connections policies (SEC-02/03).
3. Batch 4 RLS + indexes.
4. Batch 5, then Batch 6.
5. Verify with a two-business integration test using the anon key.
